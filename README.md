## Project Overview
The Online Book Store is a web-based e-commerce application developed as part of a Web Programming project. The website provides users with a simple and convenient platform to browse books, manage their shopping cart, and place orders online.
The system also includes a dedicated administrative panel that allows administrators to manage the bookstore, including products, users, orders, and customer contacts.

## User Features
Users can:
* Browse available books
* View book details and information
* Add books to the shopping cart
* Remove books from the shopping cart
* Update the quantity of items in the cart
* Proceed to checkout
* Place orders
* Manage their account
* Contact the bookstore

## Admin Features
Administrators can:
* Access the admin dashboard
* Add and manage books
* Edit and delete products
* View and manage registered users
* View and manage customer orders
* View and manage customer contacts
* Monitor the bookstore's products and orders

## Database
MySQL is used to store and manage the application's data, including:
* Users
* Products
* Orders
* Shopping cart information
* Customer contacts



## Project Purpose
The main purpose of this project is to demonstrate the development of a dynamic e-commerce website using web programming technologies. It applies concepts such as server-side programming, database connectivity, user authentication, shopping cart functionality, order processing, and administrative management.
